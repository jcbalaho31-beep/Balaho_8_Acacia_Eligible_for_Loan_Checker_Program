# Balaho_8_Acacia_Eligible_for_Loan_Checker_Program

## Description
The program checks if a user is eligible for a loan based on requirements (having at least a credit score of 700, annual income of 30,000, and having a stable employment for at least 2 years) which need to be inputted.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required information.

## Input Needed
- Credit Score
- Annual Income
- Number of years of having a stable employment

## Sample Output
- Enter your credit score: 710
- Enter your annual income: $35000
- How many years have you been in your current job? 3
- Loan Approved
